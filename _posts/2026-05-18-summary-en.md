## [OpenClaw Developer's $1.3M Monthly Bill from Running 100 OpenAI Codex Agents](https://www.tomshardware.com/tech-industry/artificial-intelligence/openclaw-creator-burns-through-1-3-million-in-openai-api-tokens-in-a-single-month) ⭐️ 8.0/10

OpenClaw developer Peter Steinberger revealed a monthly OpenAI API bill of $1.3 million, which was incurred over 30 days by running approximately 100 Codex agents that processed 603 billion tokens and made 7.6 million requests. This case provides a concrete, extreme example of the financial scaling challenges for unbounded AI-driven software development automation, highlighting that deploying autonomous coding agents at scale can incur massive, potentially unforeseen operational costs. The high cost was primarily due to the use of Codex's "fast mode" pricing, which is significantly more expensive; without it, the raw API cost would have been around $300,000. Notably, Steinberger is an OpenAI employee, so the company covered the full expense, and the experiments utilized the GPT-5.5 model dated April 23, 2026.

**Background**: OpenAI's Codex is an AI agent designed for software engineering tasks like writing code and fixing bugs, which can run in cloud sandbox environments. The service offers a "fast mode" that generates tokens at an accelerated rate for a premium price, roughly 2.5 times the standard cost. GPT-5.5 is a large language model released by OpenAI in April 2026, marketed as their smartest model for complex professional work.
