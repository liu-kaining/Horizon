After more than a decade of development, Project Valhalla's long-awaited features for value types and memory layout optimizations are scheduled to arrive in JDK 28. This is a major milestone for the Java platform, as Valhalla's value types promise substantial performance improvements by enabling more efficient memory layout and data access patterns, particularly for high-performance and data-intensive applications. Value types, also known as inline classes, are designed to be identity-free and can be flattened into arrays and object fields, reducing memory overhead and improving cache locality. The changes require both syntax additions to the Java language and significant modifications at the Java Virtual Machine (JVM) level.

rss · Lobsters · Jun 19, 14:50

**Background**: Project Valhalla is an OpenJDK initiative started around 2014 to address fundamental performance gaps in Java by introducing value types. Traditional Java objects have identity and are allocated on the heap, leading to overhead in memory and indirection. Value types aim to combine the full power of object-oriented design with the performance characteristics of primitive types by providing a way to create immutable, identity-free aggregate types.
