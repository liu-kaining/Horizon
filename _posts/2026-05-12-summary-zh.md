## [福州大学通过纳米压印转印技术实现 25400 PPI QLED 显示新突破](https://www.ithome.com/0/949/061.htm) ⭐️ 9.0/10

福州大学研究团队开发出一种“硬质纳米压印—整体倒置转印”方法，成功制备出像素密度高达 25400 PPI 的全彩 QLED 微显示器，相关成果已发表于《自然》杂志。 这一突破解决了量子点发光二极管长期面临的“高分辨率”、“全彩”与“高性能”难以兼得的核心难题，有望推动超轻量、高分辨率 AR/VR 眼镜及下一代微显示器的发展。 该技术使用坚硬的可重复使用硅模板进行精密图案化，并采用“双作用力动力学”策略实现材料的致密填充，在 12,700 PPI 的红光 QLED 中实现了 26.1%的峰值外量子效率和 65,190 小时的寿命；该工艺还兼容柔性基底和对环境敏感的钙钛矿材料。

rss · IT HOME · May 12, 00:32

**背景**: 像素密度超过 10,000 PPI 通常被认为达到了“视网膜级”标准，这对于屏幕离眼睛非常近的沉浸式 AR/VR 体验至关重要。传统的光刻和喷墨打印等方法在如此小的尺度下进行图案化时，容易出现交叉污染或性能下降，因此纳米压印等创新转印技术对于下一代微显示器至关重要。

## [TanStack 发布事后分析，详述一起复杂的 npm 供应链攻击](https://tanstack.com/blog/npm-supply-chain-compromise-postmortem) ⭐️ 8.0/10

TanStack 发布了一份详细的事后分析，揭示了攻击者如何利用恶意软件包攻破 npm 注册表，以窃取 GitHub 令牌并安装一个破坏性的死亡开关；若被窃的令牌被吊销，该开关会删除用户的主目录。 此事件凸显了开源软件供应链中持续存在的重大风险，表明一个被攻破的软件包如何能导致广泛的凭据盗窃和具有自毁功能的恶意软件，从而影响可能数以千计的下游项目。 攻击载荷安装了一个持久性服务 (`gh-token-monitor.sh`)，该服务每 60 秒使用被窃的令牌轮询 GitHub 一次，并在检测到 40x 响应（令牌无效）时，在用户系统上执行 `rm -rf ~/` 命令。

hackernews · varunsharma07 · May 11, 21:08 · [社区讨论](https://news.ycombinator.com/item?id=48100706)

**背景**: 供应链攻击通过攻破一个受信任的组件（例如一个流行的 npm 软件包）来攻击软件分发系统，从而将恶意代码传播给所有用户。死亡开关是一种机制，旨在当操作者的访问被终止时触发破坏性操作（如删除文件），起到报复性威胁的作用。GitHub 令牌是用于向自动化脚本和 CI/CD 流水线授予访问仓库及其他 GitHub 服务权限的认证凭据。
