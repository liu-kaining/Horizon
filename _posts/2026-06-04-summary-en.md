## [Elixir v1.20 Introduces Gradual Typing as a Major Language Evolution](https://elixir-lang.org/blog/2026/06/03/elixir-v1-20-0-released/) ⭐️ 9.0/10

Elixir v1.20.0 has been released, introducing a gradual type system that allows static type checking while preserving the language's dynamic nature. The initial implementation focuses on inferring types from existing code to find verified bugs without requiring changes to user code. This marks a paradigm shift for Elixir, addressing long-standing debates about the lack of static types and potentially increasing its adoption by developers who value type safety. It positions Elixir to better integrate with modern development practices, including AI-assisted coding, where typed languages can offer advantages. The implementation is based on gradual set-theoretic types and performs well in benchmarks for type narrowing, passing 12 of 13 categories. It currently requires Erlang/OTP 27+ and focuses on inference and checking, with user-provided type signatures planned for future releases.

hackernews · Lobsters · Jun 3, 19:02 · [Discussion](https://news.ycombinator.com/item?id=48388324)

**Background**: Elixir is a dynamic, functional programming language that runs on the Erlang VM (BEAM), known for its concurrency and fault tolerance. Gradual typing is a type system approach that allows mixing statically-typed and dynamically-typed code, offering a balance between safety and flexibility. Before this release, Elixir relied solely on dynamic typing and optional tools like Dialyzer for success typing, which analyzes code to find certain type errors.

Let's Encrypt has officially announced its strategic roadmap for transitioning its TLS certificate infrastructure to post-quantum cryptography to defend against future quantum computing threats. This is a major step for the world's largest certificate authority, signaling a critical paradigm shift in web security that will protect billions of encrypted connections from being decrypted by future quantum computers. The transition plan is expected to involve the integration of standardized post-quantum algorithms like ML-KEM (formerly Kyber) and likely employ a hybrid key exchange approach, combining classical and post-quantum methods during the transition period for backward compatibility.

rss · Lobsters · Jun 3, 19:07

**Background**: Post-quantum cryptography (PQC) develops cryptographic algorithms thought to be secure against attacks by powerful quantum computers, which could break widely used classical schemes like RSA and elliptic curve cryptography. The U.S. National Institute of Standards and Technology (NIST) has been leading the standardization process, with ML-KEM (Kyber) selected as a primary standard for key encapsulation. A hybrid TLS handshake uses both a classical key exchange and a PQC key encapsulation mechanism to derive the session key, providing security against both current classical and future quantum threats during the transition.

## [New HTTP/2 Bomb DoS Attack Can Crash Major Servers from a Single Machine](https://www.ithome.com/0/959/604.htm) ⭐️ 8.0/10

A cybersecurity firm using OpenAI's Codex agent discovered a novel HTTP/2-based denial-of-service attack that can crash major web servers from a single machine by rapidly exhausting their memory within seconds. This attack has a high amplification ratio and affects widely-used servers by default, posing a severe real-world threat that could enable attackers to disrupt services with minimal resources. The attack chains two methods: exploiting HPACK compression for header amplification (e.g., 5700:1 ratio in Envoy) and using HTTP/2 flow control to stall connections, with tests showing a single client exhausting 32GB RAM in about 10 seconds on Envoy.

rss · IT HOME · Jun 4, 00:29

**Background**: HTTP/2 is a modern web protocol that improves performance through features like header compression via HPACK, which uses a dynamic table to efficiently store and index frequently-used headers to reduce data size. Flow control in HTTP/2, managed through WINDOW_UPDATE frames, regulates data transmission between client and server to prevent overwhelming either side, which this attack misuses to hold resources hostage.
